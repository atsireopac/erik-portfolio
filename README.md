# Portfólio de Erik Barbosa

Primeira versão do portfólio em Next.js, TypeScript e Tailwind CSS, com tema terminal/hacker.

## Executar localmente

Requisitos: Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Publicar

1. Revise os dados em `lib/content.ts` e as páginas.
2. Verifique que não há informações internas, credenciais ou documentos sensíveis.
3. Envie o projeto para um repositório GitHub próprio.
4. Importe o repositório na Vercel e publique.
